# due-date-calculator

### Description 

Ce projet implémente une fonction calculateDueDate qui calcule une date d'échéance en ajoutant un nombre d'heure ouvrées à une date de soumission.

1. Installation et démarage
```bash
  git clone https://github.com/samehsadine/due-date-calculator 
  cd Due-Date-Calculator
```

2. Installation de dépendance 
```bash
  npm install
```
3. 
```bash
  npm test
```
